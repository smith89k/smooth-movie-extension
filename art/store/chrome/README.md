# Chrome Web Store artwork

Made from `art/logo.svg`. Upload these in the Chrome Web Store dashboard,
under **Store listing**.

| File | Size | Where it goes |
|---|---|---|
| `icon-128.png` | 128 | extension icon |
| `promo-small-440x280.png` | 440x280 | small promo tile |
| `promo-large-920x680.png` | 920x680 | large promo tile |
| `promo-marquee-1400x560.png` | 1400x560 | marquee promo tile |

Screenshots (1280x800) must be real pictures of the extension, so they stay in `store/images/`.

SMOOTH MOVIE - how to add it to Chrome
======================================

Add it (one time)
-----------------
1. Open Chrome and go to the Smooth Movie page in the Chrome Web Store:
   https://chromewebstore.google.com/detail/amcimdojlpcdohmlcffnnhffdadjlmfl
2. Click "Add to Chrome", then click "Add extension".
3. Click the puzzle-piece icon next to the address bar, then click the pin
   next to "Smooth Movie". Now its icon (a yellow play button) stays visible.

Chrome keeps it up to date by itself.

Use it on your movie site
-------------------------
1. Open the movie page.
2. Click the Smooth Movie icon.
3. Turn on "Close pop-up tabs on this site".
4. Click "Reload page" if it asks.

Ad blocking and smoother playback are already on for every site.
Click the icon to see how many ads were blocked and pop-up tabs were closed
in that tab.

Good to know
------------
- The extension cannot make your internet faster. It saves more of the movie
  ahead of time, so short slowdowns don't stop the video.
- It helps most on free movie sites. Paid apps like Netflix lock their players,
  so it changes little there.
- When "Close pop-up tabs on this site" is on, links on that site that open
  OTHER websites in a new tab are closed too. Turn the switch off if you need one.

For the developer
-----------------
To run your own copy from this folder instead of the store version:
  1. Type  chrome://extensions  in the address bar and press Enter.
  2. Turn on "Developer mode" (top right corner).
  3. Click "Load unpacked" and pick this project folder.
  4. Turn off the store version while testing, so the two copies don't
     both run.
  After changing files, click the round arrow on the Smooth Movie card.

  npm test               quick checks (no browser)
  npm run test:browser   full check in Chrome with the extension loaded
